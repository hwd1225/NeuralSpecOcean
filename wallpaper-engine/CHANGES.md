# Changes to the upstream NeuralSpecOcean build

`wallpaper/index.html` is generated by [`tools/build.ps1`](./tools/build.ps1) from the repository's root
[`index.html`](../index.html) (the upstream standalone build). It was made and tested with upstream commit
[`e9a87c6`](https://github.com/bgbg108555/NeuralSpecOcean/blob/e9a87c6542931463282415c051352d675928a74c/index.html);
the script says whether the root file still matches that version. It makes **four insertions**.
No upstream file is modified and no upstream code is removed or rewritten.

| # | Where | What is inserted | Why |
|---|---|---|---|
| 1 | after `<meta charset="utf-8">` | `<script src="diag.js"></script>` | On-screen diagnostics (WebGL2, load progress, fps, errors) |
| 2 | before `</head>` | `<link rel="stylesheet" href="wallpaper.css">` | Hides the upstream control panels in wallpaper mode |
| 3 | in `window.oceanDebug`, before `setPlaying(on)` | `getOrbit()` and `setYawPitch(y, p)` | Lets the adapter drive camera swing and mouse parallax |
| 4 | before the last `</body>` | `<script src="wallpaper.js"></script>` | Wallpaper Engine adapter |

Everything else in this folder (`wallpaper.js`, `diag.js`, `wallpaper.css`, `project.json`, `使用說明.txt`, `tools/`) is new code for this port. `wallpaper/preview.jpg` is a square crop of upstream `docs/images/hero_coast_panorama.jpg`.

## What the adapter adds

- Wallpaper Engine settings panel (`project.json`) wired to the upstream controls through `window.oceanDebug`
- Day/night modes: follow the PC clock, a configurable day cycle, or a fixed time
- Smooth time transitions: large time changes are tweened over several seconds instead of the upstream ~1 s glide
- Camera swing that stays in front of the scene: horizontal, figure eight, circle, each with a reverse variant
- Mouse parallax (view leans toward the cursor), with strength and invert options
- Toggle for mouse drag/zoom interaction
- Pause handling (`setPaused`) for picture and sound, and Wallpaper Engine's FPS limit
- Diagnostics overlay for troubleshooting
